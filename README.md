# cash-runway-planner# ⚡ 13-Week Cash Runway & Working Capital Planner

An interactive treasury liquidity model built to forecast operational cash flow, runway solvency, and working capital shocks using the direct cash flow method.

🔗 **Live Interactive Demo:** https://thirteenweekcashrunway.netlify.app/

---

### 📌 Core Problem
Profitable businesses routinely fail due to short-term liquidity bottlenecks rather than structural insolvency. Accrual accounting masks timing discrepancies between invoice issuance and cash collection. This tool bridges that gap by modeling granular, week-by-week direct cash inflows and outflows.

### 🛠️ Key Features
- **Direct Cash Flow Modeling:** Tracks scheduled receipts, payroll, facilities, vendor payments, and tax disbursements across a 13-week horizon.
- **Liquidity Trough Detection:** Dynamically calculates minimum projected cash balances and flags solvency threshold violations against customizable safety buffers.
- **Receivables Lag Stress Testing:** Simulates multi-week accounts receivable (AR) aging delays to model cash crunches from late-paying clients.
- **Cost Inflation Sensitivity:** Allows variable percentage cost shocks across operating expenses to evaluate margin compression.

### 💻 Tech Stack
- Vanilla JavaScript (ES6+)
- Chart.js (Dynamic line visualization)
